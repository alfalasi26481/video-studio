## 2. ما بُني (محرك v2) — الحلقات 1–5 لم تُلمس
- `master-claude/src/engine/` (v1) **مجمّد**: الحلقات 1–5 تُرندر به كما هي. الدليل: `make frozen-render` يرندر 50 إطاراً منها ويقارن البكسلات بالنسخة المعتمدة — **مطابقة 100%** (1 نوفمبر).
- `master-claude/src/engine2/` (v2) نسخة من v1 بنفس الجودة + 3 مفاتيح لكل حلقة (`style`):
  - **الثيم** (ألوان + تلوين اللقطات): `ember` (الحالي) · `electric` (وردي/سماوي) · `gold` (ذهبي/فيروزي) · `mint` (نعناعي/أزرق).
  - **الافتتاحية**: `stop` (توقف! الحالية) · `question` (سؤال كبير + علامة استفهام دوّارة + حلقات نبض) · `reveal` (تُعرض النتيجة أولاً 1.1 ث ثم «إرجاع» للبداية — حلقة مفتوحة).
  - **كسر النمط**: `snap` — مسحة لونية قطرية مع صوت عند كل خطوة وعند «شاهد الفرق».
- v2 بالإعدادات الافتراضية = v1 بكسلاً ببكسل (تم التحقق على EP05).

القاعدة: لا تتكرر الافتتاحية ولا الثيم في حلقتين متتاليتين. الثوابت (الخط، شريط التقدم، الترجمة، شكل «احفظ وتابع») تبقى حتى تُعرف القناة.

**سؤال المالك: هل نغيّر عند ارتفاع مستوى التعلم؟** التوصية: **الاثنان معاً** — تغيير صغير كل حلقة (افتتاحية + ثيم) لمحاربة التكرار، وتغيير أكبر («موسم» جديد: هوية لونية + شارة المستوى) عند الانتقال من مبتدئ إلى متوسط إلى محترف. ربط التغيير بالمستوى فقط يعني حلقات كثيرة متشابهة في مرحلة المبتدئ.
