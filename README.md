# 🎬 Video Studio

تحويل نص عربي مكتوب إلى فيديو احترافي كامل: شرائح مصممة، تعليق صوتي، انتقالات ناعمة، وملف ترجمة SRT.

**يعمل من الجوال بالكامل. بدون كمبيوتر، وبدون API key.**

---

## التشغيل

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/alfalasi26481/video-studio/blob/main/video_studio.ipynb)

اضغط الزر أعلاه، ثم من قائمة Colab: **Runtime → Run all**.

## ما يفعله

| المرحلة | التفصيل |
|---|---|
| التصميم | شريحة عمودية 1080×1920 بتدرّج لوني ودعم كامل للعربية |
| الصوت | Google TTS، مع قصّ الصمت وتوحيد مستوى الصوت عند ‎-16 LUFS |
| الحركة | زووم Ken Burns باتجاه متبادل بين المشاهد |
| الدمج | انتقال ذوبان ٠.٤٥ ثانية، وفتح وختام تدريجي |
| الإخراج | MP4 ستيريو مهيّأ للويب + ملف SRT متزامن |

## تعديل المحتوى

كل مشهد بهذا الشكل:

```python
{
    "kicker": "01 / المقدمة",     # سطر صغير فوق العنوان
    "title": "العنوان الرئيسي",    # ٤ إلى ٧ كلمات
    "body": "نص توضيحي أصغر",     # سطران كحد أقصى
    "narration": "النص المسموع",   # ١٥ إلى ٣٠ كلمة
}
```

سيناريو جاهز في `scenes/aviation_ar.py`.

**قاعدة عملية:** ٦–١٠ مشاهد ≈ فيديو من دقيقة إلى دقيقتين، وهو المدى المثالي للريلز والشورتس.

## الإعدادات

| المفتاح | القيم | الوظيفة |
|---|---|---|
| `orientation` | `vertical` / `horizontal` | ريلز وشورتس / يوتيوب |
| `lang` | `ar` / `en` / `fr` | لغة التعليق الصوتي |
| `brand` | أي نص | التوقيع أسفل الفيديو |
| `transition` | `0` – `1.0` | مدة الانتقال بالثواني |
| `scene_gap` | `0.2` – `0.6` | مساحة التنفّس بعد كل جملة |
| `crf` | `18` – `26` | ١٨ جودة أعلى، ٢٦ حجم أصغر |
| `burn_subtitles` | `True` / `False` | حرق الترجمة داخل الفيديو |
| `music` | مسار ملف | موسيقى خلفية اختيارية |

---

## إضافات اختيارية

**صور خلفية:** ارفع الصور إلى `/content/assets/` ثم أضف للمشهد:
```python
"image": "/content/assets/photo.jpg"
```
يقصّها النظام تلقائياً ويضيف طبقة تعتيم ليبقى النص واضحاً.

**موسيقى:** ارفع `music.mp3` إلى `/content/assets/` ثم:
```python
vb.CONFIG["music"] = "/content/assets/music.mp3"
```

## حل المشاكل

| الخطأ | الحل |
|---|---|
| `ModuleNotFoundError` | انتهت جلسة Colab — أعد تشغيل خلايا التثبيت والمحرك |
| مربعات ▯ بدل الحروف | خلية المحرك تكشفها تلقائياً وتخبرك بالأمر المطلوب |
| `gTTS` يفشل | انقطاع إنترنت أو حد يومي — انتظر دقيقة وأعد المحاولة |
| الصوت مكتظ | `narration` طويل — قسّمه على مشهدين |
| `Session crashed` | Runtime → Restart، وقلّل عدد المشاهد |
