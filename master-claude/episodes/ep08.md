- **ما تحققت منه وما لم أتحقق منه:**
  - ✅ المسار أعلاه نصاً من صفحتين رسميتين.
  - ⚠️ الصفحة **لا تذكر زر حفظ** ولا تطبيق الجوال. لذلك الحلقة تقول «على الكمبيوتر» (الموقع أو تطبيق سطح المكتب) ولا تقول «اضغط حفظ». مسار تطبيق الجوال **غير مؤكد**.
  - ⚠️ لم أرَ الواجهة بعيني (لا وصول لحساب). أسماء الأزرار تُعرض بالإنجليزية كما في الواجهة حتى يطابقها المشاهد حرفياً.
  - من في التخطيط القديم يجد «Account» بدل «Your Claude» — مذكور في تعليق النشر لا في الفيديو (حتى تبقى الخطوة واحدة وواضحة).
- **شاشة المالك (تطبيق سطح المكتب، 1 نوفمبر، 4 صور):** أسفل اليسار دائرة بالحرف الأول + الاسم + الخطة ← قائمة أولها «Settings» (اختصار ⌘,). قائمة الإعدادات: General · Account · Privacy · Billing · Usage · Capabilities · Memory · Design systems · Reflect · Time and focus · Claude Code · Claude in Chrome · System · Extensions · Developer · Skills · Connectors · Plugins · API keys. **لا يوجد «Your Claude»** — الصفحة الرسمية لا تطابق شاشته. ⏸ الخطوة 2 معلّقة حتى يُعرف أين تقع خانة التعليمات (Account أو أسفل General — غير مؤكد). الخطوة 1 تُكتب: «اضغط اسمك أسفل اليسار، ثم Settings».
- **شاشة المالك (تطبيق الجوال، 2 نوفمبر، 3 صور):** القائمة الجانبية: Projects · Code · Artifacts · Scheduled، والحرف الأول للاسم في دائرة أسفل اليسار. الإعدادات: Profile · Billing · Usage · Capabilities · Claude Code · Connectors · Permissions · Color mode · Font style · Voice · Haptic feedback · Notifications · Time & focus · Privacy · Sharing · Log out. **لا يوجد Account ولا Memory ولا Instructions في الجوال** ← الحلقة تبقى «على الكمبيوتر». مكان الخانة في الجوال غير مؤكد (ربما داخل Profile — لم يُفتح). ⏸ الخطوة 2 ما زالت تحتاج Settings ← Account على الكمبيوتر.
- إصلاحات مراجعة 1–7: الختام بلا «كل يوم»، و«شاهد الفرق» نتيجة مقروءة (3 نقاط).
