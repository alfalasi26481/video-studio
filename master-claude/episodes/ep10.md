## السكربت — عربي (نص النطق)

```
توقف! رسالة تهنئة من كلود، كأن غريباً كتبها؟ الحل بسيط: أعطه أمثلة. واحد: الصق ثلاثة أمثلة كتبتها أنت بنفسك. اثنان: نَوِّعْهَا: رسالة قصيرة، وأخرى طويلة، وثالثة لمناسبة مختلفة. ثلاثة: قل له: اكتب رسالة جديدة بالأسلوب نفسه، لصديقي بمناسبة تخرّجه. شاهد الفرق... رسالة بأسلوبك أنت، تشبهك. احفظ الفيديو، وتابعنا لمهارة جديدة.
```

## Script — English (spoken)

```
Stop! Does your greeting from Claude read like a stranger wrote it? Here's the fix: give it examples. One: paste three examples you wrote yourself. Two: vary them: a short one, a long one, and one for a different occasion. Three: tell it: write a new one in the same style, for my friend's graduation. See the difference... a message in your own style, that sounds like you. Save this video and follow for more.
```
