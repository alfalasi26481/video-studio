## السكربت — عربي (نص النطق)

```
توقف! تطلب من كلود رسالة تهنئة، فيأتيك كلام عام لا يشبهك أبداً؟ الحل بسيط: أعطه أمثلة. واحد: الصق ثلاثة أمثلة كتبتها أنت بنفسك. اثنان: نوّعها: رسالة قصيرة، وأخرى طويلة، وثالثة لمناسبة مختلفة. ثلاثة: قل له: اكتب رسالة جديدة بالأسلوب نفسه، لأخي في عيد ميلاده. شاهد الفرق... رسالة بكلماتك أنت، تشبهك. احفظ الفيديو، وتابعنا لمهارة جديدة.
```

## Script — English (spoken)

```
Stop! You ask Claude for a greeting message, and it sounds nothing like you? The fix is simple: give it examples. One: paste three examples you wrote yourself. Two: mix them up: a short one, a long one, and one for a different occasion. Three: tell it: write a new one in the same style, for my brother's birthday. See the difference... a message in your own words, that sounds like you. Save this video and follow for more.
```
